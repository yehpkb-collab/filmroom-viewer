# Film Room viewer + short links: setup

## What's in this folder
- `extension/` : **the extension source** (what you load unpacked). Edit here. This is now under git, so every release has history
- `tools/build.py` (or `tools/build.ps1`) : builds the zips from `extension/` and writes `public/download/version.json` (version, size, SHA-256)
- `dist/film-room-overlay-vX.Y.zip` : the versioned copy you send people directly (not deployed)
- `test/share-core.test.mjs` : server tests. Run `npm test`
- `public/stats/index.html` : your private link stats (`/stats/`). Needs the `STATS_TOKEN` below
- `public/index.html` : the viewer page (opens short links; plays the notes on the video and in a list)
- `public/start/index.html` : the friend-test page: download, three install steps, first note, three feedback questions (`/start/`)
- `public/start/update/index.html` : the update page for people who already have Film Room (`/start/update/`). Update its version label and "What's new" list on each release
- `public/start/guide/index.html` : the full guide: keys, emoji, sharing, troubleshooting; printable (`/start/guide/`)
- `public/download/film-room-overlay.zip` : the extension zip that page offers. **Generated by `tools/build.py`; don't copy files in by hand.** The version label and SHA-256 on the start and update pages come from `version.json`, so only the "What's new" list on the update page needs editing by hand
- `netlify/functions/share.mjs` : the short-link service (`/api/share`)
- `netlify/functions/cleanup.mjs` : daily cleanup of links nobody opened for 90 days
- `netlify/lib/share-core.mjs` : the service logic
- `netlify.toml`, `package.json` : Netlify settings

## One-time setup (about 10 minutes)
1. **GitHub:** create a new repository named `filmroom-viewer`. Click **Add file > Upload files** and drag in
   everything from this folder (`public`, `netlify`, `netlify.toml`, `package.json`). Commit.
2. **Free up the web address:** in Netlify, open your current `filmroom-viewer` site, go to
   **Site configuration > Change site name**, and rename it to `filmroom-viewer-old`.
3. **Create the new site:** in Netlify choose **Add new project > Import an existing project > GitHub**, pick the
   `filmroom-viewer` repository, and click **Deploy**. The settings come from `netlify.toml`.
4. When it's live, open **Site configuration > Change site name** and name the new site `filmroom-viewer`, so the
   address is the same one your existing links use.
5. **Check the service:** open `https://filmroom-viewer.netlify.app/api/share/AAAAAAAAAA` in a browser.
   It should say `Not found`. That means the service is running.

6. **Turn on link stats (once):** in Netlify open **Site configuration > Environment variables**, add `STATS_TOKEN` with a long random value (30+ characters), and redeploy. Then open `https://filmroom-viewer.netlify.app/stats/` and paste the token. Without the variable the stats address says "Not found", which is the safe default.
7. **Switch the Content-Security-Policy on (once, after checking):** `netlify.toml` sends it as *Report-Only*, which logs but blocks nothing. Open a short link with F12 open; if the console shows no "Content Security Policy" warnings, change `Content-Security-Policy-Report-Only` to `Content-Security-Policy` and push.
8. **Turn on two-factor** for the GitHub account and the Netlify account. The extension zip comes from this site, so these two logins protect everyone who installs it.

## From now on
To release a new extension version: change `extension/` (and bump `version` / `version_name` / `name` in `extension/manifest.json`), run `python tools/build.py`, add a line to "What's new" in `public/start/update/index.html`, then commit and push. Netlify redeploys on its own. Send friends `dist/film-room-overlay-vX.Y.zip` or the `/start/` link.

To change only the viewer or the service, edit the file and push.

Run `npm test` before pushing a change to `netlify/`.

## Sending the extension to a friend
Give them one link: `https://filmroom-viewer.netlify.app/start/`. It has the download, three install steps, the first-note keys and three feedback questions, with a link to the full guide.

## Versions
The site zip is named `filmroom-site-vX.Y.zip` (0.1 bump for a substantial change, a lowercase letter for a small one). Current: v0.8b (hosted extension zip is v0.9e). Deploy the site before (or together with) giving anyone extension 0.9: the short-link service only accepts drawings from site v0.7 on, and an older service answers 400, so sharing falls back to the long link. The extension zip is versioned separately (`film-room-overlay-vX.zip`).
